# Generic Laptop 3D Model

This GLB was created specifically for the DoGether Tech portfolio from original procedural geometry. It does not contain third-party meshes, textures, trademarks, or an Apple logo.

The project owner may use, modify, and distribute this model as part of the DoGether Tech commercial website and related marketing materials without attribution.

Generated geometry includes a physical display shell, rear lid, bezel, hinge, aluminum base, individual keyboard keys, trackpad recess, ports, speaker holes, and front lip.
